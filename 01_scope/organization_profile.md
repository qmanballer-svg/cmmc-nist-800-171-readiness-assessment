# Fictional Organization Profile

## Organization

**Falcon Ridge Defense Components (FRDC)** — fictional defense-industry subcontractor.

## Business profile

- Approximately 250 employees.
- Manufactures precision mechanical and electronic components for U.S. defense-sector customers.
- Receives and creates Controlled Unclassified Information (CUI) for selected programs.
- Uses a segmented CUI enclave rather than permitting CUI throughout the enterprise.
- Approximately 65 users are authorized for the enclave.

## Simulated technology environment

### Identity and endpoint

- Microsoft Entra ID for identity and access management.
- Multifactor authentication for enclave users.
- Microsoft Intune for managed endpoint configuration.
- Microsoft Defender for Endpoint for endpoint protection and telemetry.
- Managed Windows 11 Enterprise workstations.

### Collaboration and cloud

- Microsoft 365 GCC High for in-scope collaboration and messaging workflows.
- Azure-hosted workloads supporting selected enclave applications.
- Microsoft Sentinel for centralized security monitoring and correlation.

### Network and facilities

- Segmented corporate, CUI, and manufacturing-support networks.
- Managed firewall and VPN infrastructure.
- Controlled physical areas for enclave administration and CUI handling.
- Visitor controls and physical access logging.

## CUI use case

The fictional organization receives technical drawings, manufacturing specifications, program schedules, and related contract information that have been designated as CUI. CUI is limited to approved systems and authorized personnel within the defined enclave.

## Assessment goal

Perform a simulated readiness assessment against **CMMC Level 2 / NIST SP 800-171 Rev. 2** to determine whether the fictional environment can demonstrate implementation through adequate evidence and to identify gaps requiring remediation.

## Roles used in the simulation

| Role | Primary responsibility |

| Executive Sponsor | Risk acceptance and resource approval |
| GRC Lead | Assessment coordination, control mapping, findings and remediation tracking |
| Security Manager | Security program ownership and incident-response oversight |

| IT Operations | Endpoints, configuration, maintenance, backups and media |
| Vulnerability Management | Scanning and vulnerability remediation |

This organization and all associated details are fictional and exist only for this portfolio project.
